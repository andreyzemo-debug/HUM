Firebase setup needed

HUM's account and message storage runs on your own Firebase project, and it isn't configured yet:

To fix this:

  1. Open app.js in this project.
  2. Find the FIREBASE_CONFIG object near the top of the file.
  3. Replace every placeholder value with your real Firebase project's config — Firebase console → Project settings → General → "Your apps".
  4. Save the file and reload this page.

Full step-by-step setup (creating the project, enabling Authentication, creating Firestore, security rules) is in the comment block at the very top of app.js.
